# Архитектура FRAME

FastAPI + Jinja2 остаются SSR-приложением; PostgreSQL хранит подготовленные публикации, отдельный worker выполняет HTTP/ML. Публичные запросы не загружают источники и не запускают перевод. Существующие классификация, категории, произведения, алиасы, TMDB и RSS-адаптеры сохранены.

## Подготовка статьи

`RSSAdapter.fetch` → `IngestionService.import_article` проверяет нормализованный URL/GUID и сохраняет `DISCOVERED`. `process_article` атомарно захватывает оригинал, фиксирует `SCRAPING`, затем вызывает `ArticleScraperService`. Повторная обработка использует сохранённый фрагмент, ошибки загрузки повторяются только явной командой или после восстановления прерванного worker.

Извлечение: VarietyScraper / DeadlineScraper / AnimeCornerScraper / DramabeansScraper → GenericArticleScraper (`articleBody`, `article`, `main`, типичные контейнеры) → JSON-LD → trafilatura. JSON-LD также даёт заголовок, подзаголовок, обложку и признак платного доступа. Общий интерфейс адаптера — `container(soup, selectors)`. Новый источник добавляется формой с CSS-селекторами либо регистрируется в `SCRAPERS` небольшим классом.

Парсер сохраняет параграфы, H2–H6, форматирование, ссылки/вложения, списки, цитаты, таблицы, фигуры/подписи, picture/srcset, галереи, lazy-loaded изображения, HTML5 audio/video и поддерживаемые embeds. Он исключает навигацию, рекламу, аватары, footer/header и скрипты. Изображения/embeds имеют позицию в DOM и отдельные записи инвентаря. Сохраняется только нормализованный фрагмент статьи, не полный исходный документ.

После извлечения `PROCESSING`: хеш содержания, классификация, сопоставление событий/произведений и конфликтующих фактов. Одинаковое содержание и уверенные совпадения связывают отдельные первоисточники с одним событием. Неоднозначность создаёт `DuplicateReview`. Опубликованный текст автоматически не заменяется.

`full` использует разрешённый очищенный HTML; `facts` создаёт собственное атрибутированное изложение по метаданным и поддерживаемым явным отношениям из параграфов (трейлер, съёмки, релиз, режиссура, сценарий, кастинг, продление, производство). Сопоставленные доказательства сохраняются в `raw_data.fact_evidence`. Неподдерживаемые предложения не копируются как собственная проза; отрицания и неопределённость не превращаются в подтверждения. Разрешённая цитата ограничивается настройкой источника. Режим не является универсальной генеративной системой реферирования: объём зависит от распознанных фактов. Если кроме заголовка нет поддерживаемых фактов и разрешённой цитаты, материал остаётся FAILED с причиной; карточка со ссылкой не получает READY_FOR_REVIEW.

## Модель

- `Source`: права извлечения, `publication_mode`, `allow_media`, `allow_embeds`, `excerpt_limit`, основание прав и CSS-селекторы.
- `SourceArticle`: `canonical_url` = source URL; `title` = original title; `language` = original language; untranslated `original_html`, `sanitized_html`, `plain_text`, subtitle, featured image, scrape time/version/status/error, content hash, snapshot прав. URL глобально уникален, GUID уникален внутри источника.
- `ArticleAsset` / `article_assets`: FK оригинала, позиция, тип, URL/srcset, alt/title/caption/credit и разрешение.
- `ArticleEmbed` / `article_embeds`: FK оригинала, позиция, provider, original URL, canonical embed URL, разрешение.
- `NewsTranslation`: EN/RU/KY, title, summary, `content_html`; существующее `body` содержит производный plain text. Статус/engine/error, ручная правка, timestamps; одна версия на event/language.
- `NewsEvent`: объединённая публикация, классификация, категории, произведения, статус, reviewed, approved_by/approved_at, published_at.

Миграция `91d7a2bc410e` добавляет поля/таблицы, сохраняет старые plain-text версии как экранированные параграфы и возвращает старые события в DISCOVERED. Старое одобрение только EN не переносится как новое трёхъязычное одобрение. Downgrade сохраняет исходные plain-text поля и возвращает всё в review, не публикует автоматически.

## Перевод и статусы

DOM разбирается в переводимые текстовые узлы. Argos получает текст без искусственных идентификаторов границ: такие маркеры вызывали посторонние символы. HTML-сущности декодируются до перевода, типографская пунктуация нормализуется для модели. Служебные токены, неожиданные проценты и зацикленные повторы отклоняются; движок пробует другие гипотезы, затем сообщает ошибку вместо готового перевода. Argos переводит текст узлов, alt/title и отдельные title/summary; значения вставляются как текст, не разметка. URL, классы, iframe src, порядок и теги сохраняются. Glossary и алиасы произведений защищают имена/названия, типичные имена студий также сохраняются. Готовый HTML проверяется и повторно проходит nh3. EN служит базой для RU/KY; неанглийский источник сначала переводится в EN. Доступны прямые и pivot-пути установленных моделей; нет скрытой загрузки или английской подстановки.

`DISCOVERED → SCRAPING → PROCESSING → TRANSLATING → READY_FOR_REVIEW → APPROVED → PUBLISHED`; ветки REJECTED / FAILED. Нет назначаемого worker статуса PUBLISHED. MissingModel оставляет TRANSLATING и конкретный missing_model. `readiness_errors` проверяет все три версии, непустые поля, стабильный безопасный DOM/plain text, успешно извлечённый источник и права каждого медиа-URL. Без этого READY_FOR_REVIEW и публикация невозможны.

Администратор просматривает общий публичный шаблон по `/admin/events/{id}/preview/{en|ru|ky}`. Preview защищён сессией, no-store/noindex. Основное действие — одобрение заполненного материала; редактор HTML — дополнительная коррекция. Правка снимает одобрение, EN-правка помечает RU/KY устаревшими, ручной текст не стирается.

## Безопасность и конкуренция

nh3 allowlist используется при извлечении, переводе, редактировании и повторно при рендере. Только серверный фильтр `article_html` создаёт Markup. Скрипты, inline-обработчики, style, SVG/MathML/object/form и опасные схемы удаляются. Непроверенный HTML не проходит через Jinja safe.

`PROVIDERS` задаёт доверенные домены и канонические пути YouTube, X/Twitter, Instagram, TikTok, Vimeo; из него строится frame-src CSP. iframe получает sandbox, lazy loading, ограниченный allow и strict-origin-when-cross-origin. Этот referrer policy сохраняет идентификацию YouTube-клиента: no-referrer вызывает ошибку 153 ([YouTube API](https://developers.google.com/youtube/iframe_api_reference#onError)). Исходные сторонние скрипты никогда не исполняются. Неподдерживаемый виджет становится ссылкой; поддерживаемый также сохраняет ссылку на случай ограничений провайдера. Медиа не кешируются и не скачиваются сервером.

Публикация проверяет роль admin в маршруте и сервисе. PostgreSQL advisory transaction lock сериализует импорт, перевод, правки и одобрение. Состояние перечитывается после lock; APPROVED, PUBLISHED и audit фиксируются одной транзакцией. Повтор команды на опубликованной записи сохраняет timestamp и не создаёт второй audit. Уникальные индексы страхуют дедупликацию. Отдельный session lock допускает один scheduler. После аварии только владелец этого lock восстанавливает прерванные задания. SQLite предназначен для автономных тестов, не конкурентной эксплуатации.

Сохраняются Argon2id, signed HttpOnly/SameSite session, CSRF всех POST, rate limit входа, роли и audit. Роль editor редактирует и запускает обработку; только admin управляет правами и разрешает публикацию. robots.txt проверяется перед RSS, статьёй и при переходе редиректа; 401/403/paywall не обходятся. HTTP ограничен доменами издателя, размером 4 MB, таймаутом и backoff.

Обложка выбирается из безопасного `og:image`, затем первого фото статьи, затем JSON-LD. URL должен присутствовать в инвентаре изображений источника. Обложка отображается независимо от разрешения на медиа внутри текста; показывается в карточках и перед текстом статьи.
