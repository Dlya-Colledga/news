# Учебные материалы для показа FRAME

Обычная команда `news seed` создаёт **только категории и настройки источников**. Реальные новости импортируются отдельно. Чтобы не подменять факты, примеры для защиты курсовой полностью вымышлены и помечены словом «Демо».

После запуска `docker compose up --build -d` можно выполнить:

```bash
docker compose exec web news seed-demo
docker compose exec web news seed-demo   # повторно ничего не добавит
```

При нестандартном имени администратора: `docker compose exec web news seed-demo --admin YOUR_ADMIN_USERNAME`.

Команда доступна только при `ENVIRONMENT=development`. Она добавляет две опубликованные учебные статьи (фильм и сериал) и одну ожидающую модерации (аниме). Все тексты EN/RU/KY написаны вручную. Демонстрационные источники выключены, ничего не скачивают из интернета и не выдают вымысел за настоящие новости. Не запускайте её на публичном развёртывании.

Для реального перевода RSS-материалов нужны установленные языковые модели Argos. Контейнер `models` устанавливает маршруты EN↔RU и EN↔KY. Убедитесь, что команда `docker compose ps -a` показывает успешное завершение `models`; если загрузка не удалась, посмотрите `docker compose logs models` и повторно запустите `docker compose up models`. Оставшиеся ошибки `missing_model` для RU/KY автоматически повторяются worker после установки маршрутов. Отсутствие модели для перевода исходного текста на EN может требовать повторной обработки статьи в редакции.
